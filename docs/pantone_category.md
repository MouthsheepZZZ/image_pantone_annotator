### 核心总结

1.  **先确定你的行业**：你是做印刷品，还是做衣服，还是做塑料玩具？这是选择正确系统的第一步。
    *   **印刷/数字** -> **Graphics (PMS)**
    *   **纺织/涂料** -> **Fashion, Home + Interiors (FHI)**
    *   **塑料制品** -> **Plastics**

2.  **再明确你的目的**：你是要指定一个精确的颜色，还是要在四色印刷中模拟它？
    *   要**指定专色** -> **Formula Guide**
    *   要**模拟专色** -> **Color Bridge**
    *   要**选择纺织品颜色** -> **Cotton Planner (TCX)** 系列
    *   要**选择涂料颜色** -> **Color Guide (TPG)**

3.  **看命名识系统**：
    *   `123 C` -> 平面专色
    *   `19-4052 TCX` -> 服装纺织 (棉布)
    *   `19-4052 TPG` -> 家居涂料 (纸版)
    *   `PQ-123C` -> 塑料
